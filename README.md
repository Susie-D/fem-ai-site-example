# Master.dev workshop participant starter repo

Open this folder as your project in Codex during the workshop.

## Example prompts

You can find the example prompts we’ll use throughout the workshop in the [`prompts`](prompts) folder. They cover starting a frontend from an idea, iterating with goals, debugging in the browser, working in an existing project, and creating a reusable skill. We’ll go through them together during the workshop.

## Example app

The [`user-insights`](user-insights) folder contains the example app we’ll use for several exercises. It is a working frontend built with fictional, deterministic data, so it does not require credentials or external services. The project also includes local instructions and skills that help Codex follow its existing design and development patterns.

### Start User Insights

```bash
cd user-insights
npm install
npm run dev
```

Use the local URL printed by Vite.
